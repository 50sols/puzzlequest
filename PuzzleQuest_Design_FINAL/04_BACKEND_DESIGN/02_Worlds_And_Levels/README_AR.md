# ADM02 — العوالم والمراحل (شاشة إدارة مصممة فقط)

المرجع المرئي القابل للتعديل: `LAYOUT.svg` بدقة 1440×900 وRTL بخط Tajawal، والمعاينة `PREVIEW.png`. بيانات وتفاعلات المعنى في `DESIGN.json`، وليست إجراءات عاملة أو API.

**الغرض:** نشر المحتوى المكتمل فقط، وفق المراحل المحددة في الكتالوج.

**محتوى الشاشة:** Green Valley · ترتيب المراحل. الأعمدة: المرحلة، المصدر الفني، القطع، أهلية الفتح.

**حالة الاعتماد:** `approved`؛ انظر `03_HANDOFF/OWNER_DECISIONS_AR.md` للأسئلة المطلوبة. لا تُحوَّل القيم المعروضة بـ«—» إلى صفر أو قرارات جاهزة. لا تنشئ ميزات لعبة جديدة من هذه الشاشة.

**سلوك التصميم:** في حالات Loading/Empty/Failed/Disabled/Pending/Success تبقى نفس لوحة الإدارة ومحتواها، مع تعطيل نشر/حفظ أية قيمة غير معتمدة. واجهة الرسم لا تثبت أذونات Super Admin ولا سلامة الـAPI؛ هذه اختبارات تنفيذ لاحقة.

## بعد اعتماد Q13–Q21
المستويات الجديدة: رفع → تحقق → نشر بيانات دون تحديث التطبيق. القيم والمحتوى الحاليين موثقون في `../../02_DESIGN/APPROVED_PRODUCT_RULES.json`، والرسمة أعيد تصديرها من SVG؛ لا Backend يعمل. عناصر Upload/Verify/Publish تمثل حالات تحكم لوحة الإدارة الموجودة، وتنفيذها لاحقًا محكوم بملف `../../02_DESIGN/CONTENT_PUBLISHING_CONTRACT.json`.
