# PuzzleQuest — تصميم لوحة Laravel الخلفية (ليس تطبيقًا ولا كودًا)

**13 وحدة تصميم إدارة** مخططة ومصممة SVG + PNG + DESIGN.json + README_AR.md؛ لم تُضف شاشة واحدة إلى شاشات اللاعب الأربعين. كل البيانات الاقتصادية المعروضة من `02_DESIGN/APPROVED_PRODUCT_RULES.json` المعتمد Q01–Q21 والأسئلة المتبقية Q22–Q42 وQ05-T/X/Q09-UI/Q10-USE/BG.

الحجم المرجعي 1440×900 وRTL، الألوان مأخوذة من Tokens اللعبة، وتستخدم ملفات Tajawal TTF المرفقة. المعاينات ليست لقطات من Laravel؛ لا يوجد Server أو APIs أو صلاحيات منفذة. أسماء الحقول/الأزرار في SVG لشرح ترتيب الصفحة فقط وليست واجهات تعمل.

النطاق المسموح: نظرة عامة، عوالم/مراحل وإعداد مرحلة، متجر، يومية، تقدم اللاعبين، مبنيان، الأنشطة والمجموعات الموجودة، الإعلانات الموجودة، الحساب والخصوصية والدعم، وتحديث ZIP لنظام Laravel بموجب معيار التسليم. لا إضافة لمنتج أو شاشة لاعب أو مصدر دخل.

## فحص والتفاف الحالات المطلوبة عند التنفيذ
- عند التحميل: Skeleton للقسم فقط، والحركة المالية Pending لا تعد رصيدًا محققًا.
- عند الفراغ: تعرض رسالة عدم محتوى؛ لا تولد مهمة أو عالمًا وهميًا.
- عند فشل حفظ/نشر: يبقى الإدخال مع رسالة واضحة، ولا يتغير إصدار النشر حتى التأكيد.
- العالم غير المكتمل أو غير المنشور، أو المرحلة بلا عتبات زمن معتمدة، **لا يعرض كمحتوى جاهز**.
- إدارة الاقتصاد والرصيد والنسخ الاحتياطية والتحديثات تحصر في Super Admin وفق RBAC وتدقيق، ويجب اختبار ذلك بالـBackend الحقيقي.
- نسخة شاشة System Updates تصميم فقط؛ نموذج Laravel Setup/Update ZIP وأدلة CI ليست جاهزة، ولن يُدعى خلاف ذلك.

## حدود قابلية الاستخدام
- تصميم Desktop؛ اختبار Tablet, large text, keyboard, contrast, focus, admin responsive, RTL يحتاج Prototype/تنفيذ فعلي.
- ملفات SVG قابلة للتعديل نصيًا أو في محرر متجهات؛ PREVIEW.png صورة مراجعة فقط.

## توسيع المراحل من لوحة الإدارة الحالية

ADM02 وADM03 تم تحديث رسمهما SVG ومعاينتي PNG ومواصفتيهما بحيث يظهر شريط «رفع الأصول / تحقق الحزمة / نشر معتمد». هذه عناصر تصميم للإدارة الحالية وليست API منفذة أو شاشة جديدة للاعب. الكتالوج الحي يأتي من Laravel، وخمس مراحل فقط منشورة في الإطلاق، وكل مرحلة جديدة تحتاج ملف صورة كامل وManifest وأقنعة وقطع ومراسٍ معتمدة وقاعدة وقت معتمدة؛ لا تُنشر من رفع صورة بمفردها. مواصفات توافق Flutter/Flame ومراجعة SHA-256 وRevision في `02_DESIGN/CONTENT_PUBLISHING_CONTRACT.json`.

ADM07 يعرض تكاليف المبنيين المعتمدة، ADM08 يعرض مهام Q13 وحالة Events الفارغة والصندوق والترتيب، ADM09 يعرض شروط AdMob وInterstitial. 13 وحدة إدارية إجمالًا (ADM13: سبع واجهات إعدادات)، ولا كود Backend ولا تغييرات منتج خارج النطاق.
