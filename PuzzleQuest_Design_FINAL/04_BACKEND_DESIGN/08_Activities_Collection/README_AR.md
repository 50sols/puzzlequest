# ADM08 — الأنشطة والمقتنيات (شاشة إدارة مصممة فقط)

المرجع المرئي القابل للتعديل: `LAYOUT.svg` بدقة 1440×900 وRTL بخط Tajawal، والمعاينة `PREVIEW.png`. بيانات وتفاعلات المعنى في `DESIGN.json`، وليست إجراءات عاملة أو API.

**الغرض:** مكونات اللاعب الموجودة فقط — المحتوى لم يُعتمد بعد.

**محتوى الشاشة:** أقسام موجودة بلا بيانات إطلاق معتمدة. الأعمدة: القسم، المطلوب من المالك، الشاشة المرتبطة، حالة التحرير.

**حالة الاعتماد:** `pending`؛ انظر `03_HANDOFF/OWNER_DECISIONS_AR.md` للأسئلة المطلوبة. لا تُحوَّل القيم المعروضة بـ«—» إلى صفر أو قرارات جاهزة. لا تنشئ ميزات لعبة جديدة من هذه الشاشة.

**سلوك التصميم:** في حالات Loading/Empty/Failed/Disabled/Pending/Success تبقى نفس لوحة الإدارة ومحتواها، مع تعطيل نشر/حفظ أية قيمة غير معتمدة. واجهة الرسم لا تثبت أذونات Super Admin ولا سلامة الـAPI؛ هذه اختبارات تنفيذ لاحقة.
