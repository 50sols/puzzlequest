# PuzzleQuest V1 — بوابات التسليم بعد اعتماد العلامة الرسمية وPN01–PN04

**حالة التصميم:** تم حسم قرارات Q01–Q42 وPN01–PN04 (Q40 مشروط باختبارات الأصول). الهوية الأساسية الرسمية مدمجة، و40 شاشة لاعب و13 وحدة إدارة محفوظة (ADM13 تضم 8 شاشات إعدادات). **لا تصدر شهادة جاهزية تقنية كاملة دون إنهاء Q40 الفني واختبارات الأجهزة**. قرار All-time مغلق بالإخفاء؛ يمكن البدء بمسارات التطوير غير المتوقفة على هذه الاختبارات، دون اختراع قرار.

## معتمد ومثبت في ملفات التصميم
- Q39: الشعار والنجمة والأيقونة وSplash الرسمية واردة من حزمة الهوية المرفقة، دون تعديل ألوان أو رسم بديل. تطبيق Tajawal/Lato كما تقرر سابقًا؛ إرشاد Nunito في مصدر الهوية ليس إذنًا باستبدال Lato.
- Q40: الصور الخمس وأشكال البازل الحالية معتمدة كمدخلات أولية **مشروطة** باختبار الجودة؛ لا صور/مراحل جديدة في إطلاق V1.
- PN01: الأنواع النظامية القائمة فقط؛ Events مشروطة بتفعيل حدث، ولا تسويق أو رسائل ترويجية في V1.
- PN02: إشعاران غير ضروريين خلال **نافذة متحركة 24 ساعة**، ساعات صمت محلية 22:00–08:00؛ استثناء محدود للأمان الحرج. Inbox مستقل.
- PN03: جدولة وقت محلي لكل لاعب بمعرف منطقة زمنية IANA، تخزين UTC، وإعادة جدولة المستقبل عند تغيير المنطقة؛ عدم إرسال Normal Push مجدول حين تجهل المنطقة.
- PN04: أقصى تأخير عادي 6 ساعات فقط بشرط صلاحية الرسالة وحدود الإرسال وساعات الصمت؛ لا دفعة متأخرة أو تكرار. الأمن الحرج يستأنف فقط إن ظل صالحًا.

## بوابات جودة التصميم/الأصول قبل اعتماد Q40 فنيًا
1. مراجعة صور PNG المتطابقة داخل 100 قطعة، والفرق بين الأقنعة وحواف PNG؛ لا تغيير في الأصول المعتمدة دون مراجعة التصميم.
2. تحقق بناء لوحة 100 قطعة، اللمس والسحب والتثبيت على الهواتف الصغيرة، الأداء والذاكرة على Android وiOS.
3. **Trophy معتمد:** أصل Trophy العام للإنجازات الخمسة. **All-time معتمد للإخفاء الكامل في V1**؛ عنوان Weekly Global ثابت غير تفاعلي بدلاً من التبويب التاريخي.
4. مراجعة Alpha Cutout الشعار مشتق بصريًا، وتوفير/اعتماد Android Adaptive Icon layers أو مسار موثوق لفحص أقنعة المتجر.

## بوابات نشر/امتثال فقط
- القانونية: Privacy / Terms / Retention / Minors / consent / AdMob، تسجيل موافقة المالك والمراجعة القانونية قبل الإنتاج.
- سياسة iOS لتسجيل Google دون Apple؛ التحقق من إرشادات App Store وقت النشر.
- cPanel على PHP حتى 8.4 ليس اختبارًا لتوفر MySQL/Cron/Queue/SSL؛ Web Installer + Admin ZIP Updates+Backup+Recovery مطلوبة أثناء التنفيذ قبل الإصدار.
- FCM/APNs Android/iOS على أجهزة حقيقية، Push permission/OS icon/links/delivery، ساعات الصمت/DST وتغطية انقطاع الخدمة.
- اختبار الاستقبال الفعلي لـ`info@50sols.com`.

**الفحوص الحالية ثابتة فقط**: JSON/SVG/PNG/TTF وبصمات ومسارات، مقارنة Alpha وحواف ومراسي Puzzle. لا Flutter ولا Flame ولا Laravel ولا OS Push اختُبر تشغيلها.

## اختبار مراجع Firebase الجديدة قبل النشر
ملفا `google-services.json` و`GoogleService-Info.plist` متوافقان بنيويًا ومعتمدان كمراجع عميل؛ **لا يوجدان مفتاح APNs أو صلاحيات خادم FCM HTTP v1**. لا تُخزن هذه الأسرار في ZIP التسليم. فحص إعداد Google OAuth Android، وإشعارات الجهاز الفعلية على Android/iOS، وتهيئة APNs في Firebase Console، وأذونات OS وQueue/HTTPS بوابات نشر واختبار ما زالت مفتوحة. راجع `04_BACKEND_DESIGN/13_System_Settings` و`03_HANDOFF/MOBILE_CONFIG_REFERENCES`.


## بوابات تكامل OAuth المضافة من لقطة العميل العامة — 25 نوفمبر 2026
- Web OAuth Client `PuzzleQuest-Backend` سُجل كمرجع عام فقط؛ اعتمد المالك فصل Cloud `puzzlequest-515809` لتسجيل Google عن Firebase `puzzlequest50sols` الخاص بالهاتف/Push. هذا ليس قرارًا ناقصًا؛ اختيار مسار التكامل والتحقق منه تقنيًا خلال التطوير مطلوب. **هذه ليست شهادة نجاح تسجيل دخول.**
- ملف Android ليس فيه OAuth clients، وiOS plist لا يحتوي CLIENT_ID/REVERSED_CLIENT_ID؛ لا يجوز اختلاق معرّفات تطبيق أو بصمات SHA. أكد المالك أن Native OAuth Clients غير منشأة بعد؛ تنشأ خلال التطوير بعد توفر التوقيعات وربط المنصتين وقبل اختبارات Google Login.
- إذا كان المسار Native ID Token → Laravel token verification، قد تظل Origins وRedirect URIs فارغة. إذا اختير Web redirect لاحقًا تُعتمد روابط HTTPS الحقيقية، ولا تُنشأ Callback وهمية.
- اختبار Google على Android وiOS، Google token audience والتحقق على الخادم، والمراجعة لـApple Guideline 4.8 شروط منفصلة. لا client secrets في الأرشيف.
