# PuzzleQuest Game v1.2.0+5 — GATE / موانع إطلاق الإنتاج

1. **Flutter SDK غير متاح في مكان تجميع ZIP**: فحص بناء Android/iOS وتحليل Dart واختبارات Flutter **للنسخة 1.2.0** لم تُجر هنا. افتح المصدر على Mac، نفذ أوامر README، واحفظ تقارير التشغيل الفعلية.
2. **توليد منصات Native عند النقل**: يحتوي ZIP على كود وإعدادات Android/iOS الصالحة للمصدر، لكن Gradle wrapper JAR وملفات Xcode pbxproj يتم إنشاؤها فقط من Flutter SDK في جهاز البناء. على Mac المستخدم هذه الملفات سبق توليدها، فلا يجب حذفها أثناء الاستبدال.
3. **الـBackend Production**: صورة المحاكي بتاريخ 25-11-2026 أظهرت «الخدمة غير مهيأة». اعتماد المستندات القانونية الفعلية (8 AR/EN) وبوابة `legal_approved` واختبارات Guest Login/OTP والكتالوج مطلوبة قبل اعتبار الاتصال يعمل.
4. **DOC03 pixel/asset**: توثيق الألوان والصور المعتمدة موجود، لكن لا توجد Golden Snapshots معتمدة من المالك لحالات المكونات بالعربية/الإنجليزية أو قارئ الشاشة أو 1.3x text scale. `PQCTA` يستعمل Nine-slice للحفاظ على الزوايا؛ التحقق البصري مطلوب.
5. **تنازع الخط**: DOC03 يذكر Nunito؛ مصدر `DESIGN_TOKENS.json` / `BRAND_INTEGRATION_CONTRACT.json` المعتمد يحدد Lato. تم الاحتفاظ بـLato حتى الموافقة الصريحة على التغيير.
6. **معمارية PuzzlePiece/Board**: مدخلات اللمس لا تزال بحاجة لاختبارات Hit Polygon/Alpha وصورة مكتملة بلا Seam على جميع الأحجام، خاصة مستوى 100 قطعة ذي 3 مجموعات PNG متطابقة. لا تدّع نجاح ذلك.
7. **الميزات الخارجية**: Google OAuth Native، أذونات iOS، Push/FCM/APNs، AdMob SSV وDevice Sessions لم تُعتمد بتجارب End-to-End، والتطبيق لا يجب أن يصدر مكافآت دون تأكيد Laravel.
8. **حالات إعادة المحاولة**: يحتاج الاختبار على جهاز فعلي للتوقف في الخلفية والإعلانات واستعادة الوقت/القطع بعد قطع الشبكة وأثناء انتهاء المرحلة.

**القرار:** حزمة SOURCE DEVELOPMENT؛ ليست APK أو AAB أو IPA نهائيًا ولا إصدار متجر مكتمل.
