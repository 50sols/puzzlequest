PuzzleQuest Studio 1.0.9 - إصلاح التوافق النهائي مع كود استيراد Laravel المرفق
1) فك QuickFix داخل مجلد PuzzleQuest_Studio مع استبدال الملفات.
2) شغّل launch_windows.bat.
3) غيّر World ID إلى المعرف الحقيقي الموجود في صفحة العوالم والمراحل إذا كان مختلفًا عن green-valley.
4) حدد صورة + 100 قطعة + Display Code 1-6 + عناوين عربية وإنجليزية + أوقات 1800/900/1440.
5) صدّر ملف Laravel ZIP وارفعه من صفحة نشر أصول المراحل.
البرنامج يعيد توليد PNG 960x960 والقطع PNG والأقنعة SVG ويجري Quality Gate على جميع المكونات.
لا يمكن إثبات world_id أو نجاح الاستيراد النهائي دون استخدام قاعدة بيانات الإنتاج مع وجود GD.
