# حزمة Setup المضمّنة — للتثبيت النظيف فقط

`PuzzleQuest-Setup-v1.0.2-cPanel-Subdomain.zip` مبنية من `PuzzleQuest_Code/backend` باستخدام `tools_build_cpanel_setup.py`.

**مهم: بما أن PuzzleQuest منشور عندك بالفعل، لا ترفع هذه الحزمة فوق الموقع ولا تفكها فوق `puzzlequest_app` الحالي.** للمطور الاحتفاظ بها لاختبار تثبيت نظيف على استضافة منفصلة/نسخة تجريبية. تحديث الموقع الحالي يحتاج Update ZIP متوافقًا وموقعًا، ونسخة احتياطية تم التحقق منها.

التثبيت النظيف فقط: من cPanel File Manager ارفع Setup ZIP إلى `/home/solscool/`، فك الضغط مرة واحدة، واضبط SSL وMySQL، ثم افتح `https://puzzlequest.50sols.com/install/`. لا تحتاج لتغيير Document Root؛ الملفات العامة تُنشأ داخل الدومين الفرعي والخاصة خارجه. يجب توفير متطلبات PHP الأساسية؛ لم نجتز في هذه الجولة اختبار MySQL على استضافتك.

ملفات الخطوط الثنائية غير متضمنة في النسخة المعاد بناؤها؛ يجب توريدها من أصول المشروع المرخصة قبل الإطلاق البصري.
